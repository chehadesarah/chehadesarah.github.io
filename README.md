# CEDAR Quantum Lab website

Static, responsive site designed for GitHub Pages.

## Pages
- `index.html` — lab-first homepage
- `research.html` — four research thrusts
- `people.html` — lab lead, future members, collaborators
- `publications.html` — selected publications
- `opportunities.html` — student/collaboration inquiries and formal openings
- `teaching.html` — teaching and mentoring philosophy
- `service.html` — outreach and professional service

## Before publishing
1. Confirm the preferred institutional affiliation and email address.
2. Add a current professional headshot to the People page if desired.
3. Add CV PDF and a CV link in the navigation/footer.
4. Review the selected-publication list for completeness and publication status.
5. Replace any general wording about the lab with institution-specific language after an appointment is finalized.

## GitHub Pages deployment
Copy the files into the root of `chehadesarah.github.io`, commit, and push. Because all links are relative, no build step is required.

## Brand
`assets/img/cedar-mark.svg` is a simplified graph/network interpretation of the approved CEDAR concept. It is intentionally easy to sketch: one spine, two branching graph layers, one enclosing orbit, and nodes.
